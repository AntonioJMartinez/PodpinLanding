## Connect Google Search Console

1. Sign in to the intended owner account at https://search.google.com/search-console/ and add the confirmed website.
2. Prefer a Domain property if DNS access is available: copy Google's exact TXT record to the domain's DNS provider, then verify. This covers protocols and subdomains.
3. Alternatively use a URL-prefix property matching the canonical HTTPS origin. Select HTML tag and set GOOGLE_SITE_VERIFICATION to only the content value, not the complete meta tag. Set SITE_URL to the confirmed origin in the hosting build environment.
4. Run npm test, then npm run build:site and npm run check:site with production environment values. Publish dist/. Tests restore a preview build, so production build must follow tests.
5. Check the live homepage source for the exact verification value, then click Verify. Keep the token configured for subsequent builds.
6. Submit the live /sitemap.xml in Search Console. Inspect the homepage, one feature, one guide, and a localized page; request indexing for representative URLs. Sitemap submission does not guarantee indexing.
7. Record the initial Performance and Page indexing baseline. Monitor clicks, impressions, CTR, queries, country, device, and page over comparable periods. Avoid drawing conclusions before data accumulates.
